# RadioLog

Log de comunicações de rádio emergência (REER-PR / RENER) — aplicativo web instalável que
funciona offline no computador e no celular. Registra a rede em tempo real, importa logs em
.txt e gera ICS 309 (PDF), CSV, TXT, QR code e boletins para SSTV, APRS e voz.

Projeto independente do RadioForge (programador de rádios).
